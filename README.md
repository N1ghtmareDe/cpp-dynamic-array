# Часть 2. Исключения

Поверх части 1: все проверки заменены на выброс исключений нужного типа.

| Ситуация | Исключение |
|---|---|
| Нет памяти (`new` в конструкторе, копировании, `push_back`) | `std::bad_alloc` |
| Индекс вне границ (`get`, `set`) | `std::out_of_range` |
| Значение вне `[-100, 100]` (`set`, `push_back`), размер `<= 0` | `std::invalid_argument` |

`push_back` выделяет новую память до удаления старой, поэтому при `bad_alloc` исходный массив остаётся целым.

## Сборка
```bash
make        # собрать
make run    # собрать и запустить
make clean  # очистить
```
